# Archive

This directory contains archived historical documentation and legacy
orchestrator files synthesized into the canonical `/context/` baseline. Do
not reference these files for active development.

Directory structure under this folder mirrors each file's original path in
the repository (for example `docs/archive/docs/project-context.md`,
`docs/archive/apps/api/docs/adr/0012-freeze-showcase-api-contract.md`) so
history and cross-references remain traceable. `AGENTS.legacy.md` and
`CLAUDE.legacy.md` are the repository's prior root orchestrator files,
superseded by the current root [`AGENTS.md`](../../AGENTS.md) and
[`CLAUDE.md`](../../CLAUDE.md), which point to [`context/`](../../context/).
