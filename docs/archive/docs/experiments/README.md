# Experiment records

Use one record per material feasibility, data, feature, model, or evaluation
run. This is the lightweight, reviewable bridge to a future experiment tracker;
it does not replace a model registry when models are promoted operationally.

Create a record from
[`experiment-record-template.md`](experiment-record-template.md). Keep records
sanitised and link to secure-storage manifests rather than embedding data or
artifacts.
