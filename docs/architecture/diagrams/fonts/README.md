# Diagram fonts

Static instances of [Inter](https://github.com/rsms/inter) (Regular, SemiBold,
Bold, Italic), cut from the variable font at weight 400/600/700 and optical size
14. Inter is the Payments design system's data font and the fallback for its UI
font, Satoshi, which is not redistributable here.

Inter is Copyright 2016 The Inter Project Authors and is licensed under the SIL
Open Font License, Version 1.1: <https://openfontlicense.org>. D2 embeds a
subset of these into each rendered SVG, so the diagrams look the same wherever
they are viewed.
